# HackManager frontend

React, Vite and TypeScript. Run `npm ci` then `npm run dev` from this directory. Open http://localhost:8080 and run Express on port 8000. Set `VITE_API_URL` only when the API uses a different origin from the configured proxy.

Run `npm test`, `npm run lint` and `npm run build`. See [project setup](../README.md) and [Playwright CLI workflows](../docs/express-development.md).
